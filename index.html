  • 팀 공통 작업으로 GitHub Actions와 PM2 기반 배포 파이프라인을 구성해 main 병합 시 EC2 반영 자동화

Description.

아이돌·스타·일러스트 디지털 포토카드를 사고팔고 교환하는 컬렉션 플랫폼입니다. 마이갤러리와 포토카드 생성을 맡았습니다.

What did I do.
  • 필터를 바꾸면 상단 요약·필터 UI까지 리렌더되고 재조회마다 필터 UI가 리마운트되던 문제를, 필터·검색·페이지 상태와 목록 쿼리를 별도 섹션 컴포넌트로 내리는 상태 콜로케이션으로 해결
  • 초기 로딩(isLoading)과 값 보유 상태의 재조회(isFetching)를 구분해, 재조회 중에도 필터·검색 UI가 마운트를 유지하도록 로딩 처리를 목록 영역으로 국소화
  • 월 포토카드 생성 횟수 제한을 백엔드 me 응답 하나를 두 화면이 함께 조회하도록 설계하고, 버튼 클릭·폼 제출·서버 응답 3단계로 게이팅
  • 에러 코드별 처리 방식을 ERROR_HANDLER 테이블로 중앙화. 생성 후 잔여 횟수가 갱신되지 않던 원인이 mutation의 me 쿼리 무효화 누락임을 확인해 수정
Result.

필터 변경 시 리렌더가 목록 영역으로 한정되고 필터 UI의 상태가 유지됩니다. 잔여 횟수가 두 화면에서 일치하며 생성 직후 새로고침 없이 갱신됩니다.
